# PIKAS Mascot System v0.1

Everything needed to bring PIKAS, the PIKAS mascot, into the app and the public website.

**Start here:** `AGENT_BRIEF.md` — rules, where the mascot goes, accessibility, motion and the website plan, written for whoever (person or coding agent) integrates it.

- `brand/mascot/` — the assets to ship: 36 poses, 7 animations, master art, palette tokens, and `manifest.json` describing every file.
- `docs/PIKAS-Mascot-System-Proposal.md` — the full system: character analysis, personality, consistency rules, catalog, usage maps, motion, visual modes, accessibility.
- `previews/` — review sheets, `pikas-catalog.html` (every pose and animation, live) and `el-valle-de-pikas-prototype.html` (website scroll prototype, chapters 0–1). Open the HTML files in a browser.
- `reference/react/` — reference components for a React / Next.js codebase.
- `source/` — scripts that regenerate all art from shared parts.
