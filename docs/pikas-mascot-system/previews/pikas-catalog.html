PIKAS Mascot Catalog

All 35 planned assets are drawn: 34 poses and the loader, plus six more animations. Version 0.1 for owner review. Every pose is built from the same vector parts, so a change to the head or body carries through all of them. Use Copy SVG to take any file.

All animation is CSS inside the SVG: no player library needed. Each file turns its motion off when the viewer's device asks for reduced motion, leaving a still pose.
